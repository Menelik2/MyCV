Login & access files

This admin page opens the full Decap CMS so you can edit portfolio content files (content/*.json) and media. Production login uses GitHub.

Ready to sign in
Click Open CMS login (or wait a moment). Use the GitHub account that can push to the portfolio repository.
  1. Open CMS login (GitHub OAuth on Vercel).
  2. Authorize the app when GitHub asks.
  3. Browse Portfolio sections and open a file (About, Projects, Resume…).
  4. Edit → Save / Publish — changes commit to the repo and deploy.
Requirements
Vercel env: GITHUB_CLIENT_ID, GITHUB_CLIENT_SECRET. GitHub OAuth callback: /api/callback. Locally: run npx decap-server with local_backend: true.
